# 0.1.8 審查項目修正：0.1.9

日期：2026-11-17。原審查版本：`68cce16`。分支：`feat/ui-localization`。

## 新增語系的測試限制（P2）

語言選單與設定值的測試改從 `locales/index.json` 取得支援清單，逐一檢查
各語系及其別名。不再將法文或德文固定視為不支援的語系；拒絕行為使用無法成為
語系識別值的測試輸入，避免新增翻譯時必須修改 JavaScript。

貢獻流程回歸測試會在獨立暫存專案中產生法文、德文範本，填入合成譯文，
執行產生與一致性檢查後，再跑實際測試套件。子程序僅排除貢獻流程測試本身，
避免遞迴執行。範例資料不代表正式法文或德文翻譯，發布語系仍為英文與台灣繁中。

## 未知模型名稱漏翻（P3）

Antigravity 對話脈絡解析結果新增 `modelKnown`，明確區分缺少／預留模型名稱與
來源真正提供的模型名稱。顯示層只對明確未知的模型使用 `context.unknownModel`：
英文為 `Unknown model`，台灣繁中為「未知模型」。

保留解析結果原有的英文備援文字及數值欄位，顯示投影不修改來源資料。
真實來源模型即使恰好叫做 `Unknown model`，也會保留其名稱，不用文字相等判斷未知狀態。
測試涵蓋缺少、非字串、預留識別值、空白及清理後為空的模型名稱，以及真實來源標籤。
瀏覽器檢查另驗證中文「未知模型」及切回英文。

## 英文錯誤訊息重複維護

移除 `usageState.js` 中七則重複英文錯誤訊息，資料層保留錯誤碼，顯示層依訊息鍵值
從語系檔取得文案。錯誤狀態、最後成功讀值及來源時間的處理維持原有行為。
回歸測試逐一檢查七種錯誤碼與所有已註冊語系的顯示結果。

## 驗證

- 79 項主測試通過，包含新增語系後執行測試套件的隔離回歸案例。
- 語言檔一致性與 JavaScript 語法檢查通過。
